# PUB Crypto AI — PUB Neural Integration V0

PUB Neural is the durable cognitive layer. PUB Crypto remains the operational runtime.

## Write path
PUB Crypto emits:
- observations;
- research runs;
- decisions;
- risk events;
- executions;
- trade outcomes;
- postmortems;
- candidate lessons/patterns.

## Read path
PUB Crypto can query Neural for:
- prior decisions on the same market/strategy;
- validated lessons;
- known failure patterns;
- strategy history;
- relevant research;
- governance rules and constraints.

## Promotion
Learning follows a controlled path:
`CAPTURED → OBSERVED → EXTRACTED → CANDIDATE → VALIDATED → ADOPTED → INSTITUTIONAL`

PUB Neural does not directly place trades. It supplies context and memory. The risk and execution planes remain authoritative.

## Provenance
Every retrieved Neural item used in a decision must retain its node/event identifier and retrieval timestamp in the decision record.
